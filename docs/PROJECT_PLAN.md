# Project development plan

The current commit establishes a clean repository and reproducible environment without changing the original modelling methodology.

Planned technical stages:

1. Validate datasets and assign unique match identifiers.
2. Rebuild rolling team form without future-data leakage.
3. Correct tournament importance and venue features.
4. Calculate pre-match Elo ratings.
5. Replace random splitting with chronological evaluation.
6. Add baseline, calibrated linear SVM and gradient boosting models.
7. Expand probability and calibration evaluation.
8. Replace dummy simulation inputs with team-specific states.
9. Implement the configurable tournament simulation.
10. Align the literature review and final methodology.
11. Verify a clean end-to-end execution and prepare the release.
